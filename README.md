## 4. 指定問題與個人回答

### 問題一：為什麼 "4" 要先轉成數字，才能用於本題的分攤計算？
**個人回答**：
在 Python 中，帶有引號的 `"4"` 被定義為「字串（String）」型別，本質上只是純粹的文字符號。電腦無法直接對文字進行數學除法運算（若直接執行 `1220 / "4"` 會引發型別錯誤 `TypeError`）。因此，必須透過 `int()` 函式將其轉換為整數（Integer）數值，電腦才能正確執行數學除法，計算出正確的每人平均分攤金額。

### 問題二：如果先扣折價券，再依剩餘餐費計算服務費，第一組的應付總額會變成多少？為什麼和題目規定的結果不同？
**個人回答**：
* **計算過程**：
  1. 先扣折價券：$1200 - 100 = 1100$ 元。
  2. 再計算 10% 服務費：$1100 \times 10\% = 110$ 元。
  3. 應付總額（剩餘餐費 + 服務費）：$1100 + 110 = 1210$ 元。
* **與規定結果不同的原因**：
  題目規定的結果是 $1220$ 元。兩者不同的關鍵在於**「計算基準點」**不同：
  * **題目規定**：服務費是以「原始餐費 1200 元」計算（120元），折價券是在最後才扣抵。
  * **假設情境**：如果先扣折價券，等於讓服務費的計算基數變小了（變成用 1100 元去算 10%），導致算出來的服務費減少了 10 元，因此最終總額會變成 1210 元，比規定的 1220 元少。
